# オセロせんせい

6歳くらいの子ども向けに、オセロ盤をスマホで撮影し、おすすめの一手と理由を短く表示する Streamlit アプリです。

## 主な機能
- 「盤面を撮る」がメインのホーム画面
- カメラ画像から盤を自動切り抜き
- 8×8の黒・白・空きを自動推定
- 認識ミスを1マスずつ修正
- 黒 / 白を選択
- 合法手だけからおすすめの一手を探索
- 6歳児向けの短い理由表示
- 初級 / 中級 / 上級の「オセロを学ぶ」モード

## 起動
```bash
pip install -r requirements.txt
streamlit run app.py
```

## 注意
写真認識は、盤の色・照明・石の反射・撮影角度に左右されます。そのため、自動認識後に盤面を確認・修正できる設計です。
